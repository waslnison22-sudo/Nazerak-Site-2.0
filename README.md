# NaZerak Site 2.0

Статический лендинг NaZerak с акцентом на собственный игровой лаунчер.

- Репозиторий сайта: https://github.com/waslnison22-sudo/Nazerak-Site-2.0
- Production: https://nazerak.ru/ (не публиковать без отдельного разрешения)
- Лаунчер: https://github.com/waslnison22-sudo/NazerakLauncher
- Minecraft Java Edition: 1.21.11
- Discord: https://discord.gg/2KvsYYDHN6

## Продуктовая область

- Одностраничный лендинг проекта.
- Краткое описание мира и RP-составляющей.
- Секция NaZerak Launcher со статусом релиза.
- Discord для новостей и поддержки.
- Без форума, каталога участников, поиска и веб-кабинета.
- IP сервера не показывается: подключение должно происходить через лаунчер.

## Загрузка лаунчера

На момент последней проверки в репозитории NazerakLauncher нет опубликованных GitHub Releases. Сайт не должен имитировать наличие установщика или ссылаться на несуществующий бинарный файл. После публикации проверенной сборки обновить статус загрузки.

## Проверки

Требуется Node.js:
```sh
node scripts/qa-checks.mjs
node scripts/preview-smoke.mjs
node scripts/build-pages.mjs
```

Проверь вручную ширины 320, 390, 768, 1024, 1440 и 1920 px. Статическая проверка не заменяет визуальный браузерный тест.

## Безопасность релиза

- Не изменять Supabase, DNS, REG.RU или production в рамках локальной разработки.
- Не добавлять секреты и токены в клиентский код.
- Сохранять оригинальный фон и не заменять его низкокачественной копией.
- Не удалять старые ассеты до проверки зависимостей.
