# NaZerak Site 2.0 — актуальная спецификация

## Цель

Создать выразительный одностраничный лендинг NaZerak, который знакомит с Minecraft RP-миром и ведёт пользователя к собственному NaZerak Launcher.

- Production: https://nazerak.ru/ — не менять без отдельного разрешения.
- Репозиторий сайта: https://github.com/waslnison22-sudo/Nazerak-Site-2.0
- Репозиторий лаунчера: https://github.com/waslnison22-sudo/NazerakLauncher
- Discord: https://discord.gg/2KvsYYDHN6
- Minecraft Java Edition: 1.21.11.
- Существующий Supabase project ref: ujlbyzvdsncvqbrhasuw — не пересоздавать и не менять в рамках этой задачи.

## Объём продукта

1. Hero-секция с сильным визуальным образом и CTA на загрузку лаунчера.
2. Короткий рассказ о мире, RP и сообществе.
3. Интерактивные детали в Minecraft-стилистике без визуальной перегрузки.
4. Секция лаунчера с достоверным статусом публикации и ссылкой на настоящий релиз.
5. Discord как канал новостей и поддержки.
6. Адаптивность, клавиатурная навигация, видимый focus, reduced-motion и SEO.

Форум, участники, поиск, профили и веб-кабинет не входят в продуктовый план. IP сервера не показывается на лендинге: пользователь запускает игру через собственный лаунчер.

- Акцент: #FF2942 / #FF5F74.
- Премиальный тёмный Minecraft/RP; аккуратные стеклянные поверхности, умеренные glow и анимации.
- Сохранить исходный осенний фон `nazerak-autumn-hero.webp` без ухудшения качества. Для контраста использовать слои затемнения, не масштабировать исходник трансформациями.
- Проверять ширины 320, 360, 390, 768, 1024, 1440, 1920 px и prefers-reduced-motion.

При последней проверке GitHub Releases репозитория NazerakLauncher были пустыми. Нельзя создавать фиктивную ссылку на EXE/MSI или утверждать, что установщик готов.
